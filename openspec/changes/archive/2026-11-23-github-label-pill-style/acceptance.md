# Conditional implementation acceptance

Verdict: accepted only when an authorized human directly merges the containing exact pull-request head after required current-head validation, explicitly asks the active agent to execute that protected exact-head merge while it is currently eligible, or personally enables native auto-merge for the unchanged head and GitHub integrates it after validation succeeds.

The maintainer integration decision accepts these scenarios:
- Dark pills use Primer's perceived-lightness and rounded HSL formula, an 18% original-colour fill and a 30% adjusted-text-colour border.
- Light palettes use solid label colours with black/white text and Primer's near-white border rule, following the live panel background.
- Shared ordinary and coordinator rows retain 18px rounded pills, exact emoji names, bounded strips, full-name tooltips and unchanged metadata geometry.
- Colour regressions cover eighteen independent hue, extreme-colour and threshold samples plus dark-to-light-to-dark palette transitions.
- The merged fleet corrections retain repository sections, finished-task rows and persistent fleet presentation alongside the shared pill change.
