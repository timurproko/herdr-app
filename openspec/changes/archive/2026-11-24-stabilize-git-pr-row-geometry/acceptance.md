# Conditional implementation acceptance

Verdict: accepted only when an authorized human directly merges the containing exact pull-request head after required current-head validation, explicitly asks the active agent to execute that protected exact-head merge while it is currently eligible, or personally enables native auto-merge for the unchanged head and GitHub integrates it after validation succeeds.

The maintainer integration decision accepts these scenarios:
- Titles and three fixed row lines keep identical geometry with or without a related agent.
- Tasks, checks, labels, reviews and separators retain independent blank slots when absent.
- Optional row facts preserve neighboring anchors across three widths and five zoom levels.
- Same-context root or branch failures retain loaded rows, counts, pagination and pin measurements.
- Older active PRs stay pinned during targeted rereads after page-one refresh.
- Context changes and stale coordinator action guards retain their existing safety boundaries.
- Unknown tab totals reserve badge geometry without displaying fabricated counts.
