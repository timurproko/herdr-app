# Conditional implementation acceptance

Verdict: accepted only when an authorized human directly merges the containing exact pull-request head after required current-head validation, explicitly asks the active agent to execute that protected exact-head merge while it is currently eligible, or personally enables native auto-merge for the unchanged head and GitHub integrates it after validation succeeds.

The maintainer integration decision accepts these scenarios:
- Supported Crew project rows show Delivery workflow, Plain or Gate from versioned JSON; older Crew keeps existing path, Add and Remove behavior.
- Hover and keyboard focus reveal the shared dropdown beside a separate Remove column, with stable row geometry and Escape dismissal.
- Kind edits use the captured machine, home, name and expected folder through the advertised setter, without re-registration or direct Crew file writes.
- Matching stored-value acknowledgements update labels; refusals remain inline and uncertain results require a successful fresh read before another edit.
- Fake local and remote regressions cover capability gating, keyboard controls, geometry, single-flight operations and obsolete response rejection.
