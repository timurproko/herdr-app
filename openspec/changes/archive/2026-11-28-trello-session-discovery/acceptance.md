# Conditional implementation acceptance

Verdict: accepted only when an authorized human directly merges the containing exact pull-request head after required current-head validation, explicitly asks the active agent to execute that protected exact-head merge while it is currently eligible, or personally enables native auto-merge for the unchanged head and GitHub integrates it after validation succeeds.

The maintainer integration decision accepts these scenarios:
- A1 and Codex receive the complete Trello CLI announcement through their user skill metadata; Claude receives the matching skill in shared and isolated configurations.
- Enablement reconciliation removes owned notes when off, rejects obsolete generations and reports unavailable hosts without claiming atomic prompt revocation.
- New agent profiles prepare the owned execution-host bin for Bash, PowerShell and CMD without persistent PATH edits, policy bypasses or Core restarts.
- Existing profile arguments, coordinator launcher prefixes and previous BASH_ENV behavior are preserved; private credentials and write grants remain separate.
- Owned legacy PowerShell launchers migrate with rollback protection, while personal, modified and other-home files refuse overwrite.
