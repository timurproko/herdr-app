# Conditional implementation acceptance

Verdict: accepted only when an authorized human directly merges the containing exact pull-request head after required current-head validation, explicitly asks the active agent to execute that protected exact-head merge while it is currently eligible, or personally enables native auto-merge for the unchanged head and GitHub integrates it after validation succeeds.

The maintainer integration decision accepts these scenarios:
- The attached coordinator keeps its Crew tag; only the verified fleet child omits Crew, with unrelated plugin tags preserved.
- A thin muted vector elbow hangs beneath the coordinator badge toward the inset fleet name and also identifies the fleet in the compact rail and paired preview.
- Ordinary and attached worktree markers share the machine-chevron right axis, with Crew and other pills to their left.
- Consolidated Git has no extra task heading or generic incomplete notice, while ordinary Git controls and scoped errors remain available.
- Repository sections use the shared machine-style header, default expanded, with independent locally persisted folding and visible live Open/Closed task counts.
- Folding changes presentation only; default-off attachment, paired dragging, recorded-link eligibility and webhook-driven aggregate updates remain intact.
