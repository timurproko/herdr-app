# Conditional implementation acceptance

Verdict: accepted only when an authorized human directly merges the containing exact pull-request head after required current-head validation, explicitly asks the active agent to execute that protected exact-head merge while it is currently eligible, or personally enables native auto-merge for the unchanged head and GitHub integrates it after validation succeeds.

The maintainer integration decision accepts these scenarios:
- Initially missing window facts no longer permanently disable the observer; Windows publication starts observation without reinitialization.
- Settled copy-on-select selections use the app's standard success notification with the copied character count and no clipboard contents.
- Disabled, cleared, superseded and focus-switched selections suppress stale feedback; empty or failed clipboard reads stop after bounded retries.
- Explicit or repeated shortcut copies remain unreliable without upstream support; mouse-copy inference can still mistake held drags or unrelated clipboard changes.
