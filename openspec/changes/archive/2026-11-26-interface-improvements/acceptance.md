# Conditional implementation acceptance

Verdict: accepted only when an authorized human directly merges the containing exact pull-request head after required current-head validation, explicitly asks the active agent to execute that protected exact-head merge while it is currently eligible, or personally enables native auto-merge for the unchanged head and GitHub integrates it after validation succeeds.

The maintainer integration decision accepts these scenarios:
- Repository header counts cover deduplicated eligible task PRs in the selected tab, including folded and unrevealed rows.
- Counts reuse Agents group typography and number-to-chevron spacing without moving Git's trailing rail.
- Unknown-only repositories do not flash headers; one panel Loading indication retains deferred recovery and incomplete totals.
- Compatible coordinator returns reuse bounded runtime presentation; actionable failures remain scoped and stale facts grant no actions.
- Connected spaces use shared Agents child connectors and disclosure, truthful numbered badges and coordinator-only Crew tags.
- Parent folds preserve compact badges, native selection targets and acknowledged same-machine paired reorder; cross-machine candidates remain independent.
- The Closed-tab collapse error was investigated, not reproduced, and is left for a separate change.
- Physical pointer/keyboard and live-SSH validation was not performed; native evidence uses synthetic facts and controller/domain callbacks.
