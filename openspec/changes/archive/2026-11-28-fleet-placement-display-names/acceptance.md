# Conditional implementation acceptance

Verdict: accepted only when an authorized human directly merges the containing exact pull-request head after required current-head validation, explicitly asks the active agent to execute that protected exact-head merge while it is currently eligible, or personally enables native auto-merge for the unchanged head and GitHub integrates it after validation succeeds.

The maintainer integration decision accepts these scenarios:
- Application and internal core repair children remain attached with the correct Spaces count and disclosure on local and qualified remote models.
- Coordinator Git renders recorded task pull requests without probing its non-repository working directory.
- Legacy captions, repository aliases and case or dot spelling survive durable restoration and attachment toggles without granting stale action authority.
- Wrong task, home, project or native membership and unsafe or conflicting names still refuse binding.
