# Conditional implementation acceptance

Verdict: accepted only when an authorized human directly merges the containing exact pull-request head after required current-head validation, explicitly asks the active agent to execute that protected exact-head merge while it is currently eligible, or personally enables native auto-merge for the unchanged head and GitHub integrates it after validation succeeds.

The maintainer integration decision accepts these scenarios:
- Changing the fleet switch starts verification for applicable local and remote machines without waiting for a sidebar timer or closing Settings.
- Successful verification updates attached row order, existing numbered badges, coordinator chain and shared colour while Settings remains open.
- Disabling restores independent rows and colour immediately, and obsolete replies cannot resurrect attachment after a rapid reversal.
- Other Spaces switches save synchronously and keep their existing action-time and empty-space lifecycle behaviour.
- Mounted-dialog render guards reject focus allocation and notifications, with no guessed pair during pending or failed verification.
