# Conditional implementation acceptance

Verdict: accepted only when an authorized human directly merges the containing exact pull-request head after required current-head validation, explicitly asks the active agent to execute that protected exact-head merge while it is currently eligible, or personally enables native auto-merge for the unchanged head and GitHub integrates it after validation succeeds.

The maintainer integration decision accepts these scenarios:
- Completed nonlive reports retain read-only history, while live ambiguous membership cannot gain historical or worker authority.
- Workers independently read canonical repository and page data despite absent, empty or unverified coordinator seeds, with selected drafts below their headers.
- Native incomplete frames receive one deferred retry; caught row failures preserve healthy siblings and obsolete read leases cannot strand Loading.
- Managed aliases collapse into one emoji pill with guarded Build and Review focus, Approved PR opening, and preserved click-origin motion.
- Spaces keeps Crew and counts fixed through disclosure and aligns count, plus and Confirm independently of unchanged Agents numeric rails.
- Tab and space editors share field and action presentation while preserving captured targets, selection, cancellation and row heights.
