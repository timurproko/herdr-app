# Conditional implementation acceptance

Verdict: accepted only when an authorized human directly merges the containing exact pull-request head after required current-head validation, explicitly asks the active agent to execute that protected exact-head merge while it is currently eligible, or personally enables native auto-merge for the unchanged head and GitHub integrates it after validation succeeds.

The maintainer integration decision accepts these scenarios:
- The standard Spaces row stores one global intent, default combined, independently of selection and fleet attachment.
- Only installed Crew advertising the exact local-set v1 capability can receive an explicit-home mode change.
- Known local and connected homes, returning machines and later homes receive current intent through the existing lifecycle and transport.
- Machine-named pending, unsupported, refused and failed states preserve intent without implying partial success is global success.
- Running agents and inherited placement remain unchanged; the app never impersonates an owner, edits Crew registries directly or initializes a home.
