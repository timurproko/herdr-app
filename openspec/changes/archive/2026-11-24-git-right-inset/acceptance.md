# Conditional implementation acceptance

Verdict: accepted only when an authorized human directly merges the containing exact pull-request head after required current-head validation, explicitly asks the active agent to execute that protected exact-head merge while it is currently eligible, or personally enables native auto-merge for the unchanged head and GitHub integrates it after validation succeeds.

The maintainer integration decision accepts these scenarios:
- Git trailing control gaps match actual Spaces row highlights at 3px logical, or 3.9px at 130%, with unchanged highlight bounds, 24px targets and vertical geometry.
- Both Git tabs retain equal 8px label-left and painted-badge-right padding with centred 32px count badges and no movement between one, two and three digits.
- Fully visible exact counts have no count-only tooltip; loading zeros retain loading feedback and totals above 999 show 999+ with the exact total in their tooltip and accessible label.
- Sidebar title dropdowns use customization-owned 24px height, 4px corners and the same subtle foreground tint as inset icon buttons without changing terminal title defaults or coordinator status text.
- Complete-panel regressions cover row-relative insets and count padding at 280–480px and 75–200% zoom, including 130%, and actual title/icon hover callbacks across palettes.
- Final local supported Windows suites pass; geometry and hover assertions are synthetic, with no native pixel validation, deployment or new native patch claimed.
