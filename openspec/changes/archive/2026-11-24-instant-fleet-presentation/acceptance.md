# Conditional implementation acceptance

Verdict: accepted only when an authorized human directly merges the containing exact pull-request head after required current-head validation, explicitly asks the active agent to execute that protected exact-head merge while it is currently eligible, or personally enables native auto-merge for the unchanged head and GitHub integrates it after validation succeeds.

The maintainer integration decision accepts these scenarios:
- Last-verified host-local pair identity restores rows, chains and shared badge colour immediately across toggles and reloads without waiting for status.
- Remembered pairs support space-only block ordering while Git reads, coordinator colour writes and worker actions retain fresh verification gates.
- Recorded-only fleet verification publishes before separate lower-priority PR discovery and preserves finished Open and Draft task links.
- Capability evidence is keyed by CLI path and modification time so unchanged installations do not rerun help for every read or mod copy.
- Recurring Spaces ownership and two-second task liveness recover cancelled or replaced readers without a 45-second lease wait or stale-reply publication.
- Verification failure preserves remembered presentation, authoritative absence removes it, and off clears inventory without erasing pair memory.
