# Conditional implementation acceptance

Verdict: accepted only when an authorized human directly merges the containing exact pull-request head after required current-head validation, explicitly asks the active agent to execute that protected exact-head merge while it is currently eligible, or personally enables native auto-merge for the unchanged head and GitHub integrates it after validation succeeds.

The maintainer integration decision accepts these scenarios:
- Source and runtime preference tools resolve snapshots inside the selected Herdr home, with explicit-home precedence and the deployment default.
- Host and portable visual snapshots stay outside source; legacy host copies are neither imported, migrated nor deleted automatically.
- Personal visual snapshot copies are removed from source while authored appearance defaults and existing restore safeguards remain unchanged.
- Disposable CLI and snapshot-free build fixtures cover path selection, round trips, source isolation and preserved shipped defaults.
- README documents the exact pc snapshot relocation and manual preservation of visual backups under private dotfiles ownership.
